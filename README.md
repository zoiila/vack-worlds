# VWorld | Vack Studio

## English

**VWorld** manages Paper worlds and provides isolated, temporary worlds for schematic-based minigame sessions.

- Register reusable named schematic templates and configure bounds and spawn points.
- Create a separate temporary world for each session through a request and lease API.
- Track ownership and release or recover managed worlds safely.
- Protect original schematic files and manually configured worlds from temporary cleanup.
- Keep the existing world-management commands: `/vworld` and `/vw`.

**Preview 1.1.0-preview.3** targets Java 25 and Paper 26.2. The schematic provider requires the official WorldEdit 7.4.6 plugin, installed separately. This preview is still awaiting real-player and client acceptance and production profiling. Leaf, Folia, FAWE, and other platform combinations are not claimed as verified.

This public page describes the project. Development source, technical documentation, and versioned JARs remain in the private project repository; this page provides no public binary or download.

## العربية

**VWorld** إضافة لإدارة عوالم Paper وتوفير عوالم مؤقتة ومعزولة لجلسات الميني جيم المعتمدة على المخططات.

- تسجيل قوالب مخططات بأسماء قابلة لإعادة الاستخدام وضبط الحدود ونقاط الظهور.
- إنشاء عالم مؤقت مستقل لكل جلسة عبر واجهة الطلب والإعارة.
- تتبّع ملكية العوالم المُدارة وتحريرها أو استعادتها بأمان.
- حماية ملفات المخططات الأصلية والعوالم المُعدّة يدويًا أثناء تنظيف العوالم المؤقتة.
- الإبقاء على أوامر إدارة العوالم الحالية: `/vworld` و`/vw`.

تستهدف **النسخة التجريبية 1.1.0-preview.3** Java 25 وPaper 26.2. ويتطلب موفّر المخططات إضافة WorldEdit الرسمية بالإصدار 7.4.6، وتُثبّت بشكل منفصل. ما تزال هذه النسخة بانتظار قبول الاختبار مع لاعبين وعملاء حقيقيين وقياس الأداء في الإنتاج. لم يتم التحقق من Leaf أو Folia أو FAWE أو التركيبات الأخرى.

هذه الصفحة للتعريف بالمشروع فقط. تبقى الشيفرة المصدرية ووثائق التطوير وملفات JAR ذات الإصدارات في مستودع المشروع الخاص؛ ولا تتضمن هذه الصفحة ملفًا تنفيذيًا عامًا أو رابط تنزيل.
